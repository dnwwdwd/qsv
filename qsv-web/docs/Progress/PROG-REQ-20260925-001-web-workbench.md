## 目标、范围与依赖

用户计划以现有 qsv 仓库为基础开发 Web UI。本阶段仅建立独立的 Web 文档目录和项目索引，不修改代码、数据或部署配置。后续按 PRD 先实现 V1 非 AI 工作流，再评估 V2。前置条件包括固定 qsv 二进制能力、数据设计、懒猫接口和测试环境的确认；主要风险是上游命令能力与草案不符、数据保真、资源预算及真机兼容。
