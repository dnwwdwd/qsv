# 用户默认设置与空间清理的数据方案

- 日期：2026-09-27
- 状态：依用户授权由实施者确定，代码待统一验证
- 关联：V1-SET-01—08、REQ-20260926-003

## 方案

新增 `user_settings` 表，以不透明的 `owner_key` 为主键，保存有界的设置 JSON 与更新时间。设置只含默认编码、日期时区、输出格式和导出安全策略；不保存凭据、文件路径或业务数据。原 `resources`、`jobs` 和 `recipes` 记录不迁移、不删除。数据库版本从 3 增至 4，旧库仅执行建表迁移，默认值由服务端返回。

空间分类根据本人资源记录中的字节数计算；未提交上传和任务临时目录另行统计为估计值，不计入已登记资源。预览缓存只在内存中，清理该缓存不会触碰原始文件。永久清理只作用于用户明确选择、已在回收站且不被活跃任务使用的资源；界面先展示资源名、依赖和预计释放空间。历史任务保留原有规则和输入标识，永久清理后相应来源文件会显示不可读取。

恢复与备份工具接受版本 4。新表进入 SQLite 一致备份，用户设置可随备份恢复。迁移和清理的故障路径留待用户要求的统一测试阶段验证。
