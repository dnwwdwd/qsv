## 1. 产品定义

产品面向持有 Excel、CSV、JSON 等结构化文件的用户，让用户在自己的懒猫微服上完成导入、查看、清洗、转换、关联、对比、校验、分析和导出。用户不需要学习 qsv 命令，不需要配置云端模型，也不需要先把数据导入一套业务数据库。

**V1 提供完整的非 AI 数据处理工作流。V2 增加可关闭的 LLM 助手和受限 Agent，沿用 V1 的工具、结果、任务及模板。** 双表核对是一个功能模块，产品不局限于对账。

大文件可以完整导入服务端，但浏览器不承诺一次下载或解析全部记录。用户看到的排序、筛选、统计和导出范围必须明确，不能把当前加载页的结果当成全表结果。

### 1.1 目标用户和典型任务

| 用户 | 输入与目标 | 成功结果 |
|---|---|---|
| 日常处理表格的个人用户 | 多份列名不一致的 Excel，清洗后合并 | 得到字段一致的新文件，并知道哪些数据被改动 |
| 采购、运营、库存人员 | 系统导出与供应方/盘点数据核对 | 得到缺失、键冲突和字段差异清单，能够回溯来源 |
| 开发与数据处理人员 | CSV/JSON 导出、系统迁移样本、较大数据文件 | 完成类型检查、Join、SQL、差异分析与格式转换 |
| 持续重复处理文件的用户 | 每周/月收到格式相近的文件 | 替换输入后复用模板，不反复配置所有步骤 |
| V2 AI 用户 | 能说明业务目标，但不熟悉清洗、SQL或规则配置 | AI 给出可检查的计划，批准后产生可复算结果 |

这些是目标使用场景，不代表已经验证的用户规模或付费意愿。产品不提供银行自动核销、财务审计结论或自动业务决策。

### 1.2 产品约束

必须可部署为 Web 应用，普通浏览器可用，适配懒猫免密访问与文件入口。[R09]V1 必须离线完成业务处理，不能要求 API Key。中文界面和中文错误提示为必需；英文可切换，文本需可国际化。桌面完成全部功能；手机至少能导入、查看、调整已有模板参数、运行任务、核对结果、下载和取消，复杂宽表配置仍需可操作但不承诺相同操作效率。

原始文件不被清洗、对账或 AI 操作覆盖。用户的结果必须可下载和继续使用，不能只存在于一次浏览器会话。刷新、关闭页面和断线不能丢失已提交任务。

## 2. V1 与 V2 的边界

| 能力 | V1 | V2 |
|---|---|---|
| 导入与大表预览 | 完整提供 | 沿用 |
| 清洗、转换、去重、替换 | 完整提供 | AI 可辅助生成规则 |
| 合并、拆分、Join、集合运算 | 完整提供 | Agent 可按批准计划组合 |
| 严格双表比较与容差核对 | 完整提供 | AI 建议字段映射与规则，不裁定金额 |
| 数据质量、统计、透视、受限 SQL | 完整提供 | AI 帮助生成规则、SQL和解释结果 |
| 模板、流程、任务历史、版本、导出 | 完整提供 | AI 生成的计划可转成普通模板 |
| 自然语言处理需求 | 不提供，不显示误导性可用入口 | LLM 生成可编辑、可校验计划 |
| 自动字段语义映射 | 只提供同名/别名等确定性建议，用户确认 | LLM 提供映射候选和依据 |
| Agent 多步观察与执行 | 不提供 | 受范围、预算和审批约束 |
| 模型配置与数据发送授权 | 不要求也不外发 | 用户主动开启，默认关闭 |
| 通用终端、任意代码执行 | 不提供 | 仍不提供 |
| 云端 SaaS 依赖 | 无强依赖 | 可选模型服务，本地兼容服务可用 |

V1 的“完整”指本文列明的工具和工作流均能从输入走到可追溯输出。qsv 的网络抓取、地理服务、命令行终端功能、任意脚本执行和数据库写出不属于 V1 功能承诺。发布不能仅提供一组能点击的命令入口，而缺少任务恢复、文件保真和结果导出。

## 3. 产品对象和通用语义

**资源**：原文件、已解析数据集、处理后的版本、结果视图、报告或导出文件。每个资源有名称、来源、创建时间、状态和稳定标识。

**数据版本**：一次固定的数据内容。处理或修正产生新版本，原版本可追溯。修改筛选条件不修改数据；导出时必须指向固定版本或固定视图。

**任务**：一次导入、处理、比较、校验或导出执行。保存输入、规则、进度、结果、错误和时间。重试产生新的执行记录。

**模板/流程**：可重复运行的配置，可以是一项操作，也可以是有多个步骤和数据槽位的流程。修改模板不得改变以前任务使用的规则。

**样本**：明确标注范围和抽取方式的部分数据。样本预览通过不代表全量通过。

**V2 会话**：围绕选定资源的 AI 对话和工具运行记录。数据发送授权、计划审批、实际任务结果均可查看。

### 3.1 通用行为

| 编号 | 要求 |
|---|---|
| G-01 | 所有全表操作都显示作用资源、版本与范围；样本、全量、当前筛选结果必须区分 |
| G-02 | 上传、解析、索引、计算和导出状态分别表达；未知行数和进度不伪造 |
| G-03 | 有风险的丢行、覆盖、类型转换、聚合或数据外发必须展示影响并得到确认 |
| G-04 | 每项处理默认生成副本；可以追溯输入版本与使用规则 |
| G-05 | 参数校验失败保留已填内容；任务失败保留输入、规则、错误定位和重试入口 |
| G-06 | 所有者隔离覆盖资源、模板、任务、结果、上传与下载；不通过猜测 ID 访问他人内容 |
| G-07 | 所有耗时操作可离开页面后继续，重新打开能恢复状态；取消行为必须可观察 |
| G-08 | 默认不把原始数据、字段名、样本或统计发送到任何外部服务 |
| G-09 | 规则或文件版本变化后，旧预览失效；不能批准或执行与当前显示不同的计划 |
| G-10 | 数字、日期、空值和编码规则有明确说明，不以“自动优化”静默改变业务语义 |
| G-11 | 展示真实引擎版本与能力；未支持格式/语法直接说明，不假装成功 |
| G-12 | 关键操作支持键盘和可访问名称；错误信息可被辅助技术读取，不仅依赖颜色 |

## 4. 文件范围与导入边界

| 格式 | V1 输入 | V1 输出 | 限制 |
|---|---|---|---|
| CSV、TSV | 支持 | 支持 | 可选编码、分隔符、引号、换行、表头；多行单元格按记录处理 |
| XLSX、XLS | 支持工作表/范围选择 | 输出 XLSX；不输出旧 XLS | 处理单元格值，不重算公式，不保留完整原样式 |
| XLSM、XLSB | 支持值提取 | 不输出宏工作簿 | 不执行宏；保留原文件 |
| ODS | 支持 | 支持 | 数据导出，不承诺工作簿样式保真 |
| JSON | 支持顶层对象数组及明确路径的数据投影 | 支持 | 嵌套对象/数组需要字段路径和展开策略；不自动组合所有数组 |
| JSONL/NDJSON | 支持 | 支持 | 每条记录的缺字段、null和类型冲突可定位 |
| Parquet | 支持表状字段 | 支持 | 嵌套类型需展开/字符串化/保留策略，无法表达的转换明确拒绝 |
| ZIP、RAR等普通归档包 | 不作为通用批量输入格式 | 多文件结果可导出 ZIP | 不自动解压用户上传的任意压缩包 |
| PDF、图片、Word | 不支持 | 不支持文档转换 | 不引入 OCR 或文档识别 |

格式支持基于 qsv 的 Excel、转换和 Polars SQL 能力，以及应用的保真适配；不等于保留 Excel 的公式计算引擎和所有工作簿特性。[R01][R02]

初始单文件限制为 CSV/TSV/JSON/JSONL/Parquet 5 GiB、工作簿类 256 MiB；单记录 8 MiB、单元格 1 MiB、字段 4096 列。实际解压/展开后尺寸仍受磁盘与内存预算限制。管理员可以调整保护值，界面同步显示当前上限，不能向用户承诺“无限文件”。

UTF-8、带 BOM UTF-8、GB18030、UTF-16 LE/BE 为 V1 编码范围。无法确定的编码需要确认。截断的前缀样本不当作文件损坏结论；非法编码在正式解析中定位。

## 6. V1 页面详细需求

### P01｜概览

页面帮助用户看清当前空间的资源、任务和需要处理的事项，并从最近记录继续工作。工具按用途检索由所有页面可用的全局搜索承担，不要求用户理解命令名称。未提交配置在对应工具页继续，内置示例从导入页进入；概览不承担配置编辑或示例数据展示。

| 需求编号 | 功能 |
|---|---|
| V1-HOME-01 | 全局搜索按“清洗、转换、关联、对比、校验、分析”等用途检索工具；可搜“去空格”“合并Excel”“找重复”等中文词 |
| V1-HOME-02 | 全局搜索和工具页面显示输入类型、主要输出和必要限制；从已选资源进入时自动检查格式兼容 |
| V1-HOME-03 | 查看最近资源、最近任务和失败/中断任务，进入后保持对应版本与规则 |
| V1-HOME-04 | 对应工具页可继续未提交配置；发现输入已删除/变更时提示重新绑定，不自动选另一个文件。概览通过最近记录进入已保存的工作 |
| V1-HOME-05 | 概览空状态提供导入入口；内置非敏感示例由导入页提供，示例与用户资源明确区分 |
| V1-HOME-06 | 展示当前用户空间的资源总数、运行/排队任务、失败/中断任务和已登记空间；每项数字来自服务端快照，异常任务可查看原因 |

验收：无文件和无 API Key 时仍能访问全部 V1 工具说明；选择不支持的输入不能创建假成功任务；最近活动只包含本人记录。

### P02｜文件与数据集

| 需求编号 | 功能 |
|---|---|
| V1-RES-01 | 查看名称、格式、字节数、行列数、来源、版本、创建/更新时间和可用状态；未知数显示未知 |
| V1-RES-02 | 按名称、格式、资源类型、状态和时间检索，列表分页，支持批量选择 |
| V1-RES-03 | 区分原文件、已解析数据集、处理结果和报告；可查看它们的来源关系 |
| V1-RES-04 | 重命名显示名、添加说明；不改变资源标识与历史引用 |
| V1-RES-05 | 查看版本列表、切换版本、下载原文件、作为新任务输入；不能覆盖原文件 |
| V1-RES-06 | 删除前展示仍被运行任务/保留结果/模板依赖的情况；被运行任务使用时不得物理删除 |
| V1-RES-07 | 软删除资源进入可恢复状态，默认保留7天；永久清理前显示影响范围与占用空间 |
| V1-RES-08 | 同文件重复上传可提示已有资源，但不会未经选择合并任务或泄露其他用户同名文件 |

验收：切换旧版本能够得到相同内容；删除失败保留资源；原文件名相同的两次上传不会相互覆盖。若原文件已由用户永久删除，历史报告明确显示不可再次读取原文，不伪造来源跳转。

### P03｜导入与解析

| 需求编号 | 功能 |
|---|---|
| V1-IMP-01 | 本地拖放、浏览器选择、懒猫文件选择、“用当前应用打开”进入同一导入流程 |
| V1-IMP-02 | 多文件队列展示字节进度、暂停/继续、取消、失败与重试；断线后可续传，刷新后可识别待继续上传 |
| V1-IMP-03 | 浏览器刷新后如需重新选择本地文件，明确说明并校验文件一致性；不声称拥有未授权的永久本地文件权限 |
| V1-IMP-04 | 显示真实文件类型与当前限制，拒绝不支持格式、加密工作簿和超过预算的内容 |
| V1-IMP-05 | Excel/ODS 展示所有可解析工作表、是否隐藏、行列信息；支持选择一个或多个 Sheet，多个 Sheet生成独立数据集 |
| V1-IMP-06 | 支持表头行、无表头模式、数据开始/结束范围；自动建议可修改，合并表头需用户明确扁平化策略 |
| V1-IMP-07 | CSV配置编码、分隔符、引号与空行策略；支持多行单元格，不按文本换行计行数 |
| V1-IMP-08 | JSON配置数据路径、字段投影、数组处理、缺字段与类型冲突；新增字段需要明确策略 |
| V1-IMP-09 | 提供有界预览；显示这是样本及其范围；选择不同解析配置后重新预览 |
| V1-IMP-10 | 展示字段名与类型建议，允许覆盖；重复/空字段名自动分配不冲突的内部标识，保留原名称 |
| V1-IMP-11 | 编号、手机号、证件号和长整数可以按文本保留；不得默认丢前导零或转科学计数法 |
| V1-IMP-12 | 解析错误定位到源文件、Sheet/记录、列与原因；默认阻止静默跳行，可选隔离错误行并显示数量 |
| V1-IMP-13 | 完成后显示可预览、索引中、全量可用等状态；允许在未完成统计时浏览已确认的首批数据 |
| V1-IMP-14 | 保存解析配置用于同结构文件复用；新的源文件必须重新验证字段和Sheet，不静默回退 |
| V1-IMP-15 | 提供内置非敏感示例，经真实导入流程创建资源；明确标记示例来源，不预置假资源或假任务 |

验收：指定不存在的 Sheet 返回错误，不能变成读取第一张 Sheet；支持只含表头的空表；原始文本 `000123` 和 `12345678901234567890` 不被改写；JSON null、缺字段和空字符串的差异按选定策略保留或明确报告转换损失。

懒猫文件若需经浏览器中转，应说明实际传输路径；只有验证了平台授权的服务端读取能力，才能展示“服务端直接导入”。[R07]

### P04｜数据集详情与浏览

| 需求编号 | 功能 |
|---|---|
| V1-DATA-01 | 浏览任意已索引行段及所选字段，横向/纵向快速移动；显示全局行号和来源，不把当前页行号当源行号 |
| V1-DATA-02 | 字段检索、显示/隐藏、顺序、类型和完整单元格查看；长值只缩略展示，查看全文不改变数据 |
| V1-DATA-03 | 按一列或多列全量排序；指定方向、空值位置及稳定并列规则 |
| V1-DATA-04 | 组合条件筛选：等于/不等于、包含、前后缀、范围、集合、空值、受支持的正则；分组AND/OR |
| V1-DATA-05 | 筛选/排序计算中展示状态，可取消；页面保留旧视图并标注正在更新，不将旧数据冒充新结果 |
| V1-DATA-06 | 选择范围、复制有限单元格；默认复制上限10000个单元格，超出使用导出，不一次拉取全表 |
| V1-DATA-07 | 查看字段概览及已完成统计；样本统计和全量统计有不同标识 |

**用于验收的最小业务样例**：左有 `A001/P1/10`、`A002/P2/5`、`A003/P3/8`；右有 `A003/P3/8`、`A001/P1/9`、`A004/P4/2`。按订单号+SKU匹配，数量精确比较，应得到一致1对、差异1对、仅左1条、仅右1条，左右各3条，行顺序不影响结论。

| V1-JOB-10 | 查看脱敏诊断日志和可导出的任务摘要，日志不暴露他人数据或密钥 |

验收：取消后执行器停止新增输出；只有成功提交的文件被标为可下载；重启后未完成任务显示中断，不能显示成功；浏览器关闭不影响已经提交的任务。

## 7. V1 的完整工作流验收

### W01｜多文件清洗、合并、导出

用户导入三份工作簿，确认Sheet与列名映射，先统一日期和手机号文本，再按明确键去重、按字段并集合并，导出XLSX。

必须保留三份原文件，明确报告缺列填充、日期解析失败与移除重复数量。结果资源能打开、继续筛选并再次导出；以模板保存后，下次替换文件仍执行同一组规则。没有模型配置时该流程完整可用。

### W02｜双表容差核对

用户导入不同表头的订单与发货数据，选择订单号+SKU为键、数量精确比较、金额容差0.01，并隔离重复键。

结果必须包括字段差异、仅左、仅右、键冲突、无效键、解析异常以及一致匹配对；每类可追溯原值和原位置。金额比较不使用显示出来的四舍五入结果替代原值。报告两侧数量守恒。

### W03｜大文件探索与SQL

用户上传大CSV，在索引准备期间查看首批预览，索引完成后跳到靠后行段，按字段全量筛选、运行聚合SQL、保存结果为新资源。

完整扫描期间任务可取消，页面仍可查看已有资源；不下载全部原始数据到浏览器；导出是固定查询结果，不能混入之后改变的筛选条件。

### W04｜批处理失败与恢复

用户用同一模板处理十组文件，其中一组缺字段、一组解析失败，其余成功。

页面必须逐组展示结果，不把整体批任务显示为“十组全部完成”。重试只创建被选择组的新执行，不重复提交已经成功的八组。应用重启后，可查看成功产物与中断任务；文件未完整提交不得显示可下载。

## 8. V2 页面与功能增量

V2 不更换产品的数据处理方式。已有工具继续可独立使用；AI产生的计划可以转换为V1普通模板，关闭AI后仍可运行。

| 页面 | 功能 | 与V1的关系 |
|---|---|---|
| P17 | AI助手与会话 | 从资源/规则/SQL/结果入口使用，也可选择已有会话；不规定聊天组件的位置 |
| P18 | Agent运行与计划审批 | 展示数据范围、计划、风险、调用、验证和结果；任务产物进入P15 |
| P19 | 模型、隐私与预算设置 | 可并入P16；控制Provider、凭据、发送范围、费用和能力 |

P09增加AI字段映射建议，P05/P11/P13增加AI生成规则或SQL，P10/P12增加有依据的结果解释。没有配置模型、关闭AI或模型不可用时，这些新增入口不阻断原功能。

| 需求编号 | 功能 |

| V2-AI-01 | 从明确资源版本建立会话，显示已绑定文件和获准的数据范围；添加文件须重新检查授权 |

### P18｜Agent运行与计划审批

Agent负责在限定资源内选择工具、观察实际结果、提出方案、执行获批任务并验证结果。它不获得通用终端或全盘读取权限。

| 需求编号 | 功能 |
|---|---|
| V2-AG-01 | 选择任务目标、输入资源版本、允许读取/发送范围、调用预算和停止条件 |
| V2-AG-02 | 查看计划状态：观察、规划、待批准、执行、验证、完成、失败、取消、预算暂停 |
| V2-AG-03 | 在已授权范围内查看结构、有限样本和统计，必要时提交只读检查任务；昂贵全表操作仍占执行预算 |
| V2-AG-04 | 生成数据变更计划后，展示完整步骤、影响字段、删除/去重/聚合数量口径、输出与风险，等待用户确认 |
| V2-AG-05 | 用户可批准、拒绝或修改；修改后重新校验/预览，不使用旧审批凭据 |
| V2-AG-06 | 审批绑定用户、输入版本、规则、输出范围及发送权限；输入变化、规则变化或权限扩大后重新审批 |
| V2-AG-07 | 按批准计划执行多步工具，显示每一步真实状态和任务引用；不能把模型说“执行完成”当作成功 |
| V2-AG-08 | 执行后检查行数、Schema、异常数量和对账守恒；有失败或未完成步骤不能显示完整成功 |
| V2-AG-09 | 工具报错后可提出有限修订，说明变化；自动重试不得悄悄放宽金额容差、删除异常行或跳过校验 |
| V2-AG-10 | 任务等待中暂停模型调度，避免反复付费轮询或重复提交；任务结束后继续验证 |
| V2-AG-11 | 支持停止Agent，并明确选择是否同时取消已提交的数据任务；展示仍在运行的任务 |
| V2-AG-12 | 刷新/断线后恢复事件和审批状态；未批准的计划不能因重启自动执行 |
| V2-AG-13 | 预算到达上限时暂停并说明原因；用户可查看成本后选择停止或明确增加预算 |
| V2-AG-14 | 最终报告引用实际产物、步骤、规则、验证结果和仍存在的问题；提供数据与报告下载 |
| V2-AG-15 | 成功流程可另存普通模板；保留当前运行记录，模板不携带一次性审批 |

**默认权限**：可读取已批准范围内的结构和有限统计；样本外发单独受授权控制。可以为分析生成临时视图/统计缓存；生成用户数据变更结果必须有计划审批。V2仍不支持覆盖原文件、任意删文件、读取未选资源、安装依赖、开放网络访问或自动发布结果。

**初始预算**：单次Agent最多6轮模型请求、12次工具调用、2次计划修订；单轮上下文最多24000 token；模型决策累计超时10分钟。具体模型上下文不足时进一步收紧。正在执行的已批准数据任务使用自身超时；排队不会反复消耗模型轮次。预算值是产品初值，可配置，不能被模型自行提高。

**验收**：计划批准后模型试图更换输入/容差时必须再次进入待批准；收到工具超时而任务仍运行时不得重复提交；用户停止后不再发新模型请求；“已停止Agent、数据任务继续”与“全部取消”显示不同结果。

## 9. V2 数据授权与动作审批矩阵

数据发送授权决定“什么可以给模型看”；动作审批决定“什么可以运行”。两者独立，不能相互替代。

| 动作 | 默认状态 | 需要的授权/确认 | 结果 |
|---|---|---|---|
| 读取当前资源基本结构 | AI关闭时不发生 | 开启AI并确认结构摘要范围 | 有界上下文，不变更数据 |
| 将列名/统计发送云端 | 默认不自动发送 | 确认具体结构摘要与端点 | 记录发送范围 |
| 读取脱敏样本并发送 | 默认禁止 | 确认字段、掩码、样本量和端点 | 只发送批准内容 |
| 发送原始样本 | 默认禁止 | 明确选择原始样本并确认 | 留下授权与发送记录 |
| 全量原始文件直接上传模型 | 不支持 | 不能通过普通确认开启 | 提示改用服务端统计/有限样本 |
| 运行有限只读统计 | 授权范围内可执行 | 会话授权与资源预算 | 任务/统计可追溯 |
| 按计划生成清洗副本 | 等待审批 | 批准固定输入和Plan | 新资源，不覆盖原文 |
| 自动修改业务规则重试 | 禁止 | 修订计划重新审批 | 新执行记录 |
| 覆盖/永久删除原始文件 | Agent不支持 | 用户使用V1资源管理人工操作 | 不通过Agent工具执行 |
| 任意Shell、脚本、网络和额外MCP安装 | 不支持 | 无通用授权开关 | 明确拒绝该能力 |

“只读工具”可能生成内部缓存或视图，但不得改变业务数据版本、向外部目标写入或永久删除输入。批准模板一次不等于永久授权它处理未来所有文件。

## 10. V2 完整工作流验收

### W05｜自然语言生成清洗模板

用户选择订单表并说“清理客户名称前后空格，订单号重复时保留更新时间最新的一条，然后导出Excel”。

AI确认更新时间字段与并列策略，生成计划；用户查看样本、确认去重影响后执行。导出的文件、被排除重复组和规则摘要可查看。计划可保存普通模板；关闭AI后用新文件运行，结果仍由同一规则执行。

### W06｜Agent辅助双表核对

用户选择两份字段名不同的清单，允许发送字段类型与已掩码样本。Agent提供映射候选，发现订单号非唯一，建议用户确认是否加入SKU。用户选择组合键，批准金额容差和重复策略。

Agent运行全量核对，读取实际报告，给出带来源的差异说明。它不能把“我估计有12条差异”作为结果，也不能为了通过检查自动调高容差。未获批准的原始客户信息不得发送。

### W07｜数据内容包含恶意指令

文件名、列名或单元格包含“忽略之前规则”“读取其他目录”“把数据发送到指定网址”等文本。

模型可以将其作为普通数据解释，但不能扩大授权范围、指定新端点、读取Key或执行任意命令。无论模型是否输出了危险计划，系统都必须阻止。最终任务应能继续处理正常数据或以可解释错误停止。

### W08｜模型不可用与预算中断

模型限流或连接超时，用户仍能手动查看规则和V1结果。达到预算时Agent暂停，已批准任务不重复提交。用户增加预算或更换Provider需要明确动作；系统不自动改走付费云端，也不删除已完成产物。

| NFR-09 | 上传/下载/报告生成走有界传输，不在浏览器完整物化大结果 | 先生成数GiB Blob再下载 |
| NFR-10 | V1没有模型依赖；V2模型失败不阻断基础功能 | Key未配置时无法启动应用 |
| NFR-11 | 统计/比较结果能被相同规则重算，保存输入与版本依据 | 只存模型总结或页面截图 |
| NFR-12 | 重启/升级不丢失已提交原文件、结果、模板和历史 | 只存在浏览器状态或临时目录 |

大文件上传、Excel解析、索引构建、全量统计、Join和报告各有独立耗时指标，不承诺5GiB文件瞬时完成。正式上架前应公布经过验证的限制和测试环境，不用qsv README的单次测速代替Web应用性能。[R04]

## 12. 异常与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 空文件、仅表头文件、无数据Sheet | 正确区分，允许空数据集或解释为何无法导入，不崩溃 |
| CSV内有多行单元格 | 按合法记录解析，来源行与记录编号含义说明 |
| 重复表头、空表头 | 保留全部列并生成不冲突标识，不能覆盖同名列 |
| 超长整数和前导零 | 默认保留原文本；类型转换需确认 |
| 金额格式冲突/非法值 | 明确记录错误，不当作0或空白混过去 |
| 同名文件与同名Sheet | 标识独立，命名冲突有提示，不能误绑定 |
| 单侧重复键、对侧唯一键 | 双侧该键都进入键冲突处理，不能误报缺失 |
| 相同空值和真实空字符串 | 按本次显式空值规则比较，不能依赖引擎默认 |
| 字段格式不同但语义相同 | 只有用户选择的规范化规则才能视作一致 |
| 1:N或N:M导致爆炸输出 | 预估并限制，运行超预算及时终止保留输入 |
| 导出超过Sheet/单元格限制 | 拆分、换格式或清楚失败；不静默截断 |
| 导出字符串疑似公式 | 使用已选安全策略，显示文字保真与安全的取舍 |
| 磁盘空间不足 | 拒绝新任务或中止写出，未提交结果不标成功 |
| 解析或引擎崩溃 | 错误可定位，应用可恢复；原始数据不变 |
| 网络中断/SSE断开 | 重连后读取任务快照；不重复提交任务 |
| 服务重启 | 恢复历史，将未完成任务标为中断并提供恢复选择 |
| 用户会话过期 | 暂停页面写操作，认证后恢复上下文；不转为匿名访问 |
| 用户访问他人资源ID | 统一拒绝，不泄露名称、行数或样本 |
| 模型返回无效Plan/SQL | 拒绝执行并显示可修正问题 |
| 模型返回捏造统计 | 不作为已验证结论发布，使用实际数据结果纠正 |
| 模型试图扩大授权 | 等待真实用户确认或拒绝，不自动批准 |
| 断网/无模型配置 | 全部V1数据处理继续可用 |

### 13.2 V2 必须通过

| 验收项 | 证据 |
|---|---|
| 基础不退化 | V1全量回归，AI关闭与模型不可用时不受影响 |
| 计划与工具 | LLM输出经过同一Schema、权限、SQL和业务校验，危险操作拒绝记录 |

| 结果可靠 | 模型解释引用真实任务与统计；未执行动作不能声称完成 |
| 预算与停止 | 限流、超时、停止、重连、轮次预算、幂等工具提交测试 |
| Prompt injection | W07及跨资源越权、恶意工具结果等用例受阻 |
| 会话持久化 | 刷新、重启后恢复审批和执行状态，不自动执行未授权计划 |
| 模板可迁移 | AI计划保存成普通模板，关闭AI后仍可复用 |
| 模型能力差异 | 不支持结构化输出/工具的端点得到明确能力提示，不静默降级到危险执行 |

## 14. 明确不在 V1/V2 范围内的能力

不开发完整Excel编辑器，不承诺保留宏、图表、公式重算和全部样式；不做团队实时协同、企业组织审批或行级业务权限管理；不做面向任意数据库的BI平台或ETL调度平台；不做银行自动资金核销与无共同键的任意多对多凑单。

不提供任意终端、Python/Luau脚本、安装软件、网络爬取、未知MCP扩展或全盘Agent。V2不加入与数据任务无关的长期记忆、知识库RAG、社交聊天或自动内容发布。

应用数据检查只执行已定义规则，统计异常和AI建议不构成业务真实性、会计合规或法律结论。
