- 关联需求：[REQ-20260925-002](../Requirements/REQ-20260925-002.md)。
- 状态：第一轮实现完成，待用户浏览器确认。
- 最后更新：2026-09-25。

## 目标、范围与依赖

交付一个只用 mock 数据的 PC 端前端，覆盖 PRD V1 的 P01—P16，用于确认布局、配色、菜单分组与交互方式。
不涉及后端、数据库、真实文件与部署。前置条件：Node 24 + pnpm 10.18（corepack 启用）；无外部服务依赖。
主要风险：mock 数据容易被误认为已实现的能力（用界面标注与文档控制）；视觉基线尚未经真机与真实数据量复核。

### 2026-09-26（第五轮）— 删除页头区块、统一页面宽度

- 触发：用户反馈"每个页面的宽度都没有统一，最上面的这个 card 都应该删除"，并指出首页顶部的白底页头。

  - `ui/Page.tsx`：`PageHeader`（眉标 + 24px 标题 + 说明句 + 事实行 + 主操作，136px 白底）替换为 `PageTopBar`——
    标题、内联事实、本页控件（children）与主操作都在一条 40—53px 的横条里，说明句改为标题的 `hint` 提示；
    `below` 承接展开区；`flex-wrap` + 主操作 `ml-auto` 处理换行。`PageBody` 去掉 `flush`，统一 `px-4 lg:px-6 xl:px-7`。
  - 16 个页面全部改用 `PageTopBar`：P02 把搜索、范围分段、类型筛选并入该行，P04 把筛选按钮与排序状态并入该行
    （筛选条件编辑器走 `below`），P08 的模式分段由 `tabs` 改为 children；P15/P13 的面板内 `Toolbar` 保持在面板里。
  - 宽度统一：删除 P14 的居中定宽；两栏右栏统一 320px（P02/P15 由 340/360 改）；P02 的"共 N 项"移到表格底部翻页条左侧。

    子项两两无重叠；内容左边缘都是 224px；无页面级横向溢出；无控制台错误、无错误边界。
