# REQ-20260926-004：P01 改为概览并调整职责

- 用户要求：将“工具与最近活动”改为概览页面，并修改该页面承担的职责。
- 依据：[PRD P01](../qsv_Web_PRD_V1_V2.md)、[UI 规范](../UI_GUIDE.md)、[前后端接入需求](REQ-20260926-003.md)。
- 状态：已实施，待用户验收；V1 未实现工具继续按主需求推进。

## 页面职责

1. 首页展示当前用户空间的真实资源数、运行/排队任务、失败/中断任务和已登记文件空间；数字未知时显示未知，不填演示值。
2. 失败/中断任务优先于最近活动展示，可查看服务端记录的错误，并进入任务页处理。
   已创建重试任务的旧失败记录不再重复计入“需处理”；若重试再次失败，显示最新失败记录。
3. 最近资源和任务各取最新五项，链接到真实资源、数据集或任务页；空空间提供导入入口。
4. 顶栏全局搜索承担工具、资源和任务检索；工具用中文用途关键词匹配，未实现工具明确标为尚未接入。
   资源与任务由服务端在当前用户空间检索，不受列表首页 50 项限制，结果打开对应详情。
5. 概览不编辑处理配置、不展示内置示例数据，也不根据当前行段推断全表统计。未提交配置在对应工具页继续，内置示例从导入页进入。

## 验收记录

- 浏览器在真实本机数据空间显示 22 项资源、3 项需处理任务和 28.6 MiB 已登记文件；异常任务的错误来自服务端，最近资源和任务均可打开对应页面。
- 宽 375px 时，指标、任务名称和最近活动仍可读；默认宽度下无内容溢出。顶栏搜索“去空格”返回“清洗与转换规则”，同时标明尚未接入。
- 服务端测试覆盖两个 owner 的概览隔离；B 无法读取 A 的需处理任务。
- 任务列表和详情可进入单个任务的真实执行记录；重试后打开返回任务，重试来源可从详情追溯。资源与任务列表使用游标翻页，避免新记录进入时重复或漏项。
- 最近原文件可直接打开对应资源详情，查看服务端记录的摘要、大小和时间并下载；浏览器已从概览进入该详情页核对。
- 服务端测试覆盖重试后旧失败任务不再计入提醒，以及重试任务再次失败时只提醒最新执行记录。
- 搜索接口测试覆盖列表首页外的资源以及用户空间隔离；浏览器搜索真实 CSV 后分别显示数据集、原文件和任务，点击原文件直达详情。
- 导入页已提供需用户主动点击的非真实订单示例；浏览器创建的资源与任务带“[内置示例]”名称，经真实导入执行，4 行完成。对应工具页的未提交配置续做、全部工具的输入兼容检查与真机验收仍待主需求推进。
