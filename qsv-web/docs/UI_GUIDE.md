# Web UI 规范

状态：v2 视觉与交互设计基线。当前 `qsv-web/apps/web` 仅实现其中的部分页面和组件；适用范围为 V1 的 P01—P16。
本文只规定视觉、组件与交互规则；页面功能与验收以 [PRD](qsv_Web_PRD_V1_V2.md) 为依据，实现方案以 [PPD](qsv_Web_PPD.md) 为待验证基线。
2026-09-26 起，当前前端连接真实 API；P01—P04、P15、P16 的基础信息和操作已接入，其他页面仅说明尚未可用。以下第 0—8 节保留演示阶段的设计记录，其中部分组件和交互尚未在当前实现中恢复，不能当作功能完成证明。

2026-09-26 P01 改为“概览”：指标带显示当前空间真实资源、任务和登记空间；先呈现失败/中断任务，再呈现最近资源与任务。工具检索由顶栏全局搜索承担；未提交配置在对应工具页继续，内置示例从导入页进入。原 P01 演示截图只作为历史视觉记录。

## 0. v2 修订说明

第一版视觉评审（对 P01 截图）指出：层级未拉开、几乎无阴影、一个强调色承担多种语义、首屏密度低、底栏像调试 HUD、装饰噪声多。
v2 的对应修订：

1. 画布压暗到 `0.962`、侧栏 `0.936`、面板纯白，白色面板靠 `shadow-card` 真正浮起，不再只靠 1px 描边。
2. 主色改为**深青**（hue 197），只用于主操作、当前导航项与链接；成功色改到 hue 148，与主色明显区分；运行中用 `info`，警告用 `warn`，失败用 `danger`。
3. 标题 24px，关键数字 18px，正文 14px，单元格 13px，元信息 12px，分组小标题 11.5px + 字距；数字与标题不再同级。
4. 关键数字改用**页头内联事实**或**紧凑指标带**（标签左、数字右，高约 44px），不再用大卡片吃掉首屏。
5. 底栏只留四项（版本、资源、缓存、任务计数），任务计数可点进 P15；缓存为 0 时不显示。
6. "演示数据、未连接引擎"**只在顶栏出现一次**；侧栏副标题改为"本地演示环境"，不再重复三处。
7. 左侧导航分组可折叠，默认展开全部；去掉导航里的内部页面编号。
8. 内容克制：每页只保留主流程与必要信息，列表默认最多 5–6 行，长解释进 `title` 提示。

### v2.1 响应式修订（窄屏）

用户反馈"布局不符合响应式布局，宽度较小时处理不好"，对应修订：

1. **侧栏三档**：<1024 收成 60px 图标栏（只有图标 + 悬浮提示），1024–1279 为 200px，≥1280 为 240px；导航项都带图标。
2. **两栏页面在窄屏自动堆叠**：一律写成 `grid grid-cols-1 gap-5 xl:grid-cols-[minmax(0,1fr)_320px]`（或 344/360），
   窄屏时右栏落到主内容下方，不再把主区压到 340px 以下。
3. **禁止居中定宽**：删除页面的 `mx-auto max-w-5xl`，内容铺满主区；内边距改为 `px-4 lg:px-6 xl:px-7`。
4. **指标带响应式**：`MetricStrip` 只提供 2/3/4/6 四档静态类名（2 列 → 3/4/6 列随宽度递增），窄屏自动折行。
5. **顶栏与状态条在窄屏收缩**：搜索框改为可伸缩，⌘K 与"演示数据"文案在窄屏隐藏（保留图标与提示）。
6. 实测（1024 宽）：16 个页面均无横向溢出、无内容被裁切，主区宽 824px，单栏面板 ≥765px。

### v2.3 修订（页面顶部结构与宽度统一）

用户反馈"每个页面的宽度都没有统一，最上面的这个 card 都应该删除"，对应修订：

1. **删除页头区块**：`PageHeader`（眉标 + 24px 标题 + 说明句 + 事实行 + 主操作，占 136px 白底）改为 `PageTopBar`：
   标题、内联事实、本页控件与主操作都在**一行** 40—53px 的横条里，表格类页面把自己的筛选/排序控件作为 children 传入，
   与标题合并成同一行（P04 为例：页头 136px + 工具条 49px = 185px → 单条 87px）。
   原来的页面说明句改为标题的悬浮提示（`hint`），不再占版面。
2. **宽度统一为一档**：所有页面（含表格类）都用 `PageBody` 的 `px-4 lg:px-6 xl:px-7` 内边距，取消 `flush` 贴边；
   删除 P14 残留的 `mx-auto w-full max-w-6xl` 居中定宽；两栏页面的右栏统一为 `320px`（原来是 320/340/344/360 四种）。
   实测 1176 宽下 16 个页面内容左边缘都在 224px，无页面级横向溢出。
3. **固定宽度控件必须能生效**：`Input`/`Select` 的基类带 `w-full`，会盖掉页面写的 `w-28`/`w-48` 等固定宽度
   （P02 的类型筛选曾被撑到 928px、P05 的规则下拉整行铺满）。页面上的固定宽度写法统一加 `!`（如 `w-28!`），
   让作者的意图生效；不写宽度的控件仍按 `w-full` 铺满。
4. **顶部条内的控件不再被挤成 0 宽**：搜索框这类 `flex-1` 项改为固定宽度或给最小宽度（`w-56` / `min-w-56`），
   避免一行内项目变多后被压到几像素并与相邻控件重叠。
5. 一行放不下时允许换行：`PageTopBar` 用 `flex-wrap`，主操作加 `ml-auto` 保证换行后仍靠右。

### v2.4 修订（页头保持贴边）

每页顶部的 `PageTopBar` 保持主内容区全宽，使用平直边缘和底部分隔线，不采用悬浮卡片的外边距、圆角或阴影。页头内容与 `PageBody` 使用同一组左右内边距（16/24/28px）。主区网格列使用 `minmax(0,1fr)`，长表格只在自己的容器内横向滚动，不能撑宽页头或截断页面主操作。375px 和 1280px 下检查 18 个页面路径，页头与正文容器宽度一致。

### v2.2 修订（P04 数据集页的垂直空间与冻结列）

用户反馈"这个页面的布局有问题"（980×875 截图），对应修订：

1. **主内容优先，不再上下各占一半**：P04 主体网格改为 `grid-cols-1 grid-rows-[minmax(0,1fr)_auto]`，≥1280 为
   `xl:grid-cols-[minmax(0,1fr)_344px] xl:grid-rows-[minmax(0,1fr)]`。**侧边检查器在 <1280 变成底部抽屉且默认收起**
   （只留 44—53px 页签条 + 展开按钮），展开时高度上限 `min(320px,45vh)` 且内部滚动；≥1280 仍是右侧常开。
   点表格行、点单元格全文、点页签都自动展开抽屉。理由：980×875 下表格区与检查器各 302px，百万行表格只剩 8 行可见。
2. **虚拟表格行号列冻结**：`sticky left-0`，表头与数据行同宽、同底色（`bg-inherit` 跟随斑马纹与选中态），
   列宽按最大行号字符数计算（1,000,000 行 → 83px、4,218 行 → 54px），避免末行行号溢出。
3. **底部信息条只报"当前完整可见的行范围"**（`ceil(exactRow)` 到 `floor(exactRow + 可见行数)`）；
   挂载窗口与块缓存不进文案（另有"读取中 N 块"与左侧标尺）。数字必须与画面一致。
4. **表头高度运行期测量**：行层偏移与可见行数都用实测表头高度，不再用固定 `top-7`，避免首行被表头压住 2px。
5. **标尺给最小可见刻度**：已加载区间最小 3px、当前视窗最小 2px；百万行下不再是一条空灰带。
6. 页签与面板标题不重复同一个词；检查器收起时不显示面板底部状态栏。
7. **工具条内边距与页头一致**：`Toolbar` 用 `px-4 lg:px-6 xl:px-7`（原来是固定 `px-4`），
   否则 ≥1024 时工具条左边缘比页头少 8px、≥1280 少 12px。

## 1. 视觉主题与氛围

**方向名称：精密计量台。**

面向在 PC 上长时间核对表格的采购、运营、财务与数据人员。界面像一台校准过的计量仪器：冷调中性表面、单一深青强调色、
等宽数字纵向对齐、细线只用于分隔内容而不是围合容器。克制、可核对，不像通用后台模板。

- 60/30/10：60% 中性表面（画布/侧栏/面板）、30% 次级文字与分隔线、10% 深青强调。
- 每个数字都能追溯到来源与范围；颜色不单独承担含义，永远配文字或图标。
- 只在内容确实需要独立边界时才用面板；页面区块优先用留白与分隔线分组。

## 2. 颜色与角色

OKLCH 声明，中性色向 250 相偏移极低彩度。令牌定义在 `apps/web/src/styles/theme.css` 的 `@theme` 中，令牌名即工具类名。

| 角色 | 令牌 | 值（OKLCH） | 用途 |
|---|---|---|---|
| 画布 | `canvas` | `0.962 0.005 250` | 页面底色、顶栏底 |
| 侧栏 | `rail` | `0.936 0.007 250` | 左侧导航、底部状态条 |
| 面板 | `surface` | `1 0 0` | 面板、表格底、浮层 |
| 次级面板 | `surface-2` | `0.978 0.003 250` | 次级区块 |
| 凹陷面 | `surface-sunk` | `0.948 0.006 250` | 输入底、分段控件底、标尺底 |
| 悬停面 | `surface-hover` | `0.958 0.008 240` | 行/项悬停 |
| 分隔线 | `hairline` / `hairline-soft` / `hairline-strong` | `0.918` / `0.944` / `0.868` | 结构分隔 / 行内 / 强分隔与滚动条 |
| 主文字 | `ink` | `0.225 0.018 258` | 标题与正文 |
| 次文字 | `ink-2` | `0.445 0.014 258` | 说明、表格内容 |
| 弱文字 | `ink-3` | `0.598 0.011 258` | 元信息、单位、占位 |
| 强调（深青） | `accent` 家族 | `0.545 0.108 197` | 主操作、当前导航项、链接、焦点 |
| 成功 / 一致 | `ok` 家族 | `0.600 0.110 148` | 成功任务、一致匹配 |
| 警告 / 差异 | `warn` 家族 | `0.720 0.130 72` | 字段差异、样本标识、限制提示 |
| 危险 / 冲突 | `danger` 家族 | `0.565 0.155 22` | 失败、键冲突、破坏性操作 |
| 信息 / 仅左 / 运行中 | `info` 家族 | `0.550 0.130 268` | 排队、仅左、运行中进度 |
| 紫 / 仅右 | `violet` 家族 | `0.550 0.130 305` | 仅右分类 |
| 青 / 备用 | `cyan` 家族 | `0.580 0.100 205` | 备用语义（当前未用于分类） |
| 橙 / 解析异常 | `orange` 家族 | `0.630 0.150 48` | 解析异常、需人工确认 |

核对结果七分类固定配色：一致 `ok`、字段差异 `warn`、仅左 `info`、仅右 `violet`、键冲突 `danger`、
无效键 `neutral`、解析异常 `orange`。

禁止：紫色到蓝色渐变、青色霓虹暗色体系、彩色文字叠在彩色底上、同一色相承担多种语义。

## 3. 字体与排版

- 西文与数字：`Archivo Variable`；数字与 ID：`Spline Sans Mono Variable`（`.figure` 类，等宽 + `tabular-nums`）。
- 中文：`PingFang SC` / `Hiragino Sans GB` / `Microsoft YaHei` / `Noto Sans CJK SC` 回退。
- 字号阶梯：`text-eyebrow` 11.5 / `text-meta` 12 / `text-cell` 13 / `text-body` 14 / `text-title` 17 / `text-figure` 18 / `text-display` 24。
- 分组小标题用 `.eyebrow`（11.5px + 0.06em 字距 + `ink-2`），对比度不得低于 4.5:1。
- 所有数字（行数、金额、耗时、hash、时间、缓存用量）等宽右对齐。

## 4. 组件约定

组件源码在 `apps/web/src/ui/`，页面必须复用：

| 组件 | 何时用 | 关键约束 |
|---|---|---|
| `Button` / `IconButton` | 操作 | `primary` 只用于每屏唯一主操作；尺寸 sm 28 / md 34 / lg 38；图标按钮必须给 `label` |
| `PageTopBar` | 每个页面顶部的唯一一条横条 | 标题（`text-title`）、内联事实、本页控件（children）、主操作；说明句放标题的 `hint` 提示；`below` 放展开区（如筛选条件）；一行放不下才换行 |
| `Panel` / `PanelHeader` / `PanelSection` | 内容需要独立边界时 | 面板内小节用留白与细线，不再套卡片 |
| `Toolbar` | 操作条 | 与内容之间用一条 `border-hairline` |
| `Chip` / `StatusDot` / `CountBadge` / `ScopeTag` | 状态与范围 | 颜色 + 文字同时出现；状态标签固定宽度对齐 |
| `DataTable` | 行数有界的列表 | 表头 12px `ink-3`，行高约 40px，无斑马纹，悬停高亮 |
| `VirtualDataTable` | 百万行浏览（P04） | 行块缓存 + 有界虚拟滚动 + 已加载区间标尺（最小 3px 刻度）+ 行号跳转 + 选区复制；**行号列冻结**（`sticky left-0`，宽度按最大行号字符数计算）；底部信息条只报当前完整可见的行范围 |
| `Field` / `Input` / `Select` / `Checkbox` / `Switch` / `Segmented` | 参数配置 | 控件高 34px；复选框用 `.check`（16px 圆角方块，选中填充主色）；**需要固定宽度时必须写 `w-28!` 这类带 `!` 的写法**，否则会被基类的 `w-full` 覆盖 |
| `Banner` | 影响与限制提示 | 不使用弹窗打断流程；最多一处同类提示 |
| `EmptyState` | 空列表 | 说明为什么空、下一步做什么 |
| `MetricStrip` / `Metric` | 关键数字 | 紧凑带（标签左、数字右，约 44px 高）；同页最多一处 |
| `KeyValueList` | 详情字段 | 值可换行，数字等宽 |

圆角阶梯：`rounded-xs` 4 / `rounded-control` 8 / `rounded-panel` 12 / `rounded-frame` 16 / `rounded-chip` 仅状态标签。
阴影：`shadow-card` 面板、`shadow-pop` 浮层、`shadow-rail` 1px 细环（小控件）。`border` 只用于分隔线与表格。

## 5. 布局原则

- PC 优先；**窄屏要能用**：<1024 侧栏收成 60px 图标栏，两栏页面在窄屏堆叠成一列（`grid-cols-1 xl:grid-cols-[...]`），禁止居中定宽与固定像素宽度。
- 骨架：左侧可折叠分组导航（<1024 为 60px 图标栏，1024–1279 为 200px，≥1280 为 240px）→ 顶栏 56px + 主区 + 底部 30px 状态条。
- 页面模板：`PageTopBar`（标题、内联事实、本页控件、主操作，全部在一行；页面不再有独立页头区块）→ `PageBody`（统一内边距，表格类页面也一样）。
  顶部只有这一条 40—53px 的横条，不再有 136px 的白底页头。
- 配置类页面用左右两列（主配置 + 结果/预览），两列顶部对齐；不用模态框承载主流程。
  侧边检查器/信息栏在 <1280 改为底部抽屉并默认收起，点相关内容（如表格行、单元格全文）自动展开，避免与主内容平分高度。
- 内容克制：一屏内看到主要内容与主操作；列表默认最多 5–6 行；长解释放 `title`。
- 需要固定操作的流程（如导入）在页面底部放一条 56px 操作条，与当前选择实时绑定。

## 6. 深度与层级

浅色界面靠"背景明度差 + 阴影"表达层级：侧栏比画布暗约 3%，面板纯白并带 `shadow-card`，输入与分段控件用 `surface-sunk`。
相邻嵌套面必须可分辨；禁止玻璃拟态与粗描边阴影。

## 7. 动效

- 只动 `transform` / `opacity`；时长 140ms（悬停、按压）、180—260ms（进场）；缓动 `ease-quart` / `ease-standard`，无弹跳。
- 分块进场 `.enter-block` + `--enter-index` 错峰 90ms，仅首次挂载使用。
- 按压反馈 `.press`：`scale(0.975)`，可被打断。
- 进度：有准确百分比用 `Meter`（运行中用 `info` 色），只有阶段时显示阶段文字，未知时不显示进度条。
- 遵守 `prefers-reduced-motion`。

## 8. 可访问性与交互底线

- 图标按钮必须有 `aria-label`；操作用 `<button>`，导航用 `<a>`/`Link`。
- 保留 `:focus-visible` 焦点环；键盘可达：⌘K 检索、↑↓ 选择、Enter 打开、Esc 关闭；导航分组可用键盘展开收起。
- 表格表头 `aria-sort`、行 `aria-rowindex`、单元格 `role="gridcell"`。
- 错误信息用 `role="alert"`；正文对比度 ≥ 4.5:1（当前构建的自动检查为 0 项违规）。
- 危险操作展示影响范围并要求确认，确认按钮不用主强调色。

## 9. 真实数据边界

- 页面经 `apps/web/src/api/client.ts` 请求服务端；原 `src/mock/` 数据层及浏览器任务模拟器已删除。
- 顶栏显示服务端实际报告的引擎状态；底栏的资源和任务计数来自 API。未接入的功能不生成模拟结果。
- 数字必须标注作用范围（样本/全量/当前视图）；未知就显示未知，不伪造进度与占比。
- 接入范围和接口行为以当前代码、需求记录及功能进度为准。

## 10. 已知未决

- 深色主题、英文语言包与响应式细节未设计；PRD 要求中文必需、英文可切换，本轮只交付中文。
- 视觉基线尚未经真机与真实数据量复核，最终以 PPD 第 16 节的性能与真机验收为准。
