## 本轮修复

按发现顺序，均记入 [Bug 台账](BUG_TRACKER.md)：

1. **工作簿工作表预览 422**（BUG-20261024-001，即 10-17 轮遗留问题）：`qsv excel --range` 与工作表已用区域做 `(末行, 末列)` 元组字典序比较，服务端固定请求 `A起:AD起+19`，列数超出小表实际列数即报 "larger than sheet"。修复：预览范围按工作簿元信息的行列数夹取（列上限仍 30），表头行超表时返回明确错误；数据行不足时跳过数据段。API 验证三个工作表（含隐藏）+31 行大表均正常。
2. **P09 核对提交 PREFLIGHT_STALE**（BUG-20261024-002）：`CompareField` 已有 `leftTimeZone`/`rightTimeZone`，但 `/api/v1/compares` 提交 schema 的 fields 未声明这两个属性，Fastify 按 `additionalProperties: false` 剥掉后与预检配置哈希不一致。修复：schema 补齐两个时区字符串字段（长度 ≤64，内容仍由服务端 IANA 校验把关）。修复后全流程重测通过。
3. **favicon 404**（BUG-20261024-003，轻微）：`index.html` 未声明图标，浏览器默认请求 `/favicon.ico` 每次加载报 404。修复：内联 SVG 数据 URI 图标。
