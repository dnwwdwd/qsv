# qsv-web 页面手工测试数据

这些文件是给 **每个页面各准备一份（或一对）测试数据** 用的，导入后逐项验证该页面功能是否能正常使用。命名规则：**P页码_页面简称_功能说明**。需要多个输入的页面（合并、关联、核对、质检参考数据）会出多个文件，文件名互相配对。

全部文件来自本目录的生成脚本，可重新生成或微调：

- `node gen.mjs` —— 生成全部 CSV / TSV / JSON / JSONL 文本文件
- `python3 gen_xlsx.py` —— 生成全部 xlsx（需 `pip install openpyxl`）

改动文件后请横向对比脚本，避免手改丢失。测试记录请按页面记到 `docs/` 的测试或缺陷文档。

## P07 合并、关联与集合

| 文件 | 用途 |
|---|---|
| **P07_合并_华东华南.csv** + **P07_合并_西南东北.csv** | 同结构纵向合并（strict/union/intersection） |
| **P07_关联_左侧订单.csv** / **P07_关联_右侧订单.csv** | 左表 5 行；左独有 O-1003、O-1004，右独有 O-2001，用于左/右/全/半/反关联 |
| P07_关联_多对多左表.csv / P07_关联_多对多右表.csv | 两侧键均有重复（B-1、B-1），选「多对多：允许重复展开」看展开行数 |

关联建议键：左右表都选 `订单ID`，两侧键均唯一，一对一/一对多/多对一预检都应通过。`P07_关联_右侧订单.csv` 缺少左表的 `客户ID` 列，适合验证并集合并的补空与缺列场景。

核对建议（P09，键两端都是 `订单ID`）：
- `金额` → 十进制数值，绝对容差 0.5：O-1005 两侧 25 与 25.50 恰在容差边界通过，O-1002 120 与 180 差 60 报差异
- `下单日期` → 日历日期，允许相差 1 天：O-1005 两侧相差 1 天通过，O-1001 通过
- `更新时间` → 带时区时间点，左/右侧时区都填 Asia/Taipei，允许相差 30 秒：O-1002 两侧相差 10 分钟报差异
- 仅左（O-1003、O-1004）、仅右（O-2001）覆盖「只在单侧」的分类；要测键冲突，可手工把某行追加成重复键
