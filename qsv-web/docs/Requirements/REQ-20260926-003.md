# REQ-20260926-003：Web 前后端接入并移除演示数据

## 状态与依据

- 分类：跨前端、API、后台任务、文件、认证、持久化与平台的新功能。
- 状态：进行中；数据方案已确认，基础 CSV 流程已接通，P01—P16 主要功能代码已分批写入但尚未统一验证，细节仍需补齐。
- 用户要求：以本仓库 qsv 为底座，按 [PRD](../qsv_Web_PRD_V1_V2.md) 与 [PPD](../qsv_Web_PPD.md) 开始前后端对接，并移除 mock 数据。
- 2026-09-27 范围调整：用户要求暂时不做懒猫微服移植与适配。当前继续完成普通浏览器下的 V1 功能；懒猫真机、LPK、平台身份和文件选择不计入这一轮完成判定。
- 关联总需求：[REQ-20260925-001](REQ-20260925-001.md)；现有演示前端：[REQ-20260925-002](REQ-20260925-002.md)。
- 数据方案：[DEC-20260926-002](../Decisions/DEC-20260926-002.md)；[功能进度](../Progress/PROG-REQ-20260926-003-web-integration.md)。

## 目标与边界

V1 页面只展示服务端实际存在的资源、任务、模板、行块和计算结果。上传传输字节数、任务状态、引擎版本与可用能力来自真实接口；刷新后仍能读取已提交的数据。处理默认生成新资源版本，原始文件不覆盖。产品不把尚未实现的操作显示成成功或填入演示结果。V2 AI 不在本次范围内。

接入前的 `qsv-web/apps/web/src/mock/` 内存层承担资源、任务、导入、视图、报告和设置。现已删除该层及引用它的旧页面、任务模拟器；新页面从 `apps/server` 读取真实状态。懒猫部署产物仍未建立。

## 写入、读取、状态与安全

| 范围 | 目标行为 |
|---|---|
| 写入 | 文件选择与传输、导入确认、资源重命名/删除/恢复、视图创建、任务提交/取消/重试、模板保存、设置修改均调用服务端；写请求有幂等键或版本前提。 |
| 读取与恢复 | 首页、资源、数据集、任务、模板、报告、设置、全局搜索和状态条从同一 API 读取。刷新和重新登录后获取快照；SSE 只通知刷新，不作为唯一事实来源。 |
| 失败与取消 | 无网络、未授权、格式不支持、解析失败、磁盘不足、qsv 失败和取消均保留输入与可读错误；只有服务端确认提交的文件可下载。 |
| 权限 | 资源、上传、视图、任务、模板、结果与下载按服务端验证的 owner 隔离；不接受页面传来的文件路径或 owner。 |
| 平台 | 普通浏览器为基本路径；懒猫免密、文件选择与下载须在真机验证。未验证的能力明确标注。 |
| 已检查且不受影响 | qsv 原有 CLI 命令实现、测试及原 `docs/` 不因 Web 对接改动。 |

## 分阶段方案

1. 固定 qsv 构建与能力、文件语义、SQLite 运行版本；整理 API 和数据方案。对不可用的能力保持禁用状态。
2. 数据方案确认后建立服务端、迁移和 owner 隔离；先完成真实上传 → 导入 → 资源 → 数据集行块 → 下载，以及任务快照、取消和恢复。当前只完成其中的基础路径，重启恢复及平台隔离仍需验收。
3. 将页面逐个接入对应的实际操作和结果；移除 fixture、浏览器内任务模拟器及静态成功文案。复杂全表操作必须经过受限计划和后台任务。
4. 完成浏览器、API、断线/重启、权限、边界数据与懒猫真机验证，再按 PRD 验收 V1。

具体阶段证据记录在功能进度文档。用户已授权并确认数据方案，三表迁移已执行；后续变更仍须对照已确认的数据语义。
