# REQ-20260926-005：页面顶部保持全宽平直样式

- 用户要求：每个页面的顶部区域不改成悬浮卡片，宽度与页面宽度统一。
- 依据：[UI 规范](../UI_GUIDE.md) 第 v2.3—v2.4 节；影响 `PageTopBar`、`PageBody` 与应用主区网格。
- 状态：已实施，待用户验收。

## 具体行为

1. 每页顶部区域贴合主内容区完整宽度，只有底部分隔线；没有外边距、圆角和投影。
2. 顶部内容和正文使用相同的 16/24/28px 响应式左右间距；窄屏操作换行，仍可见。
3. 表格等宽内容由页面内部滚动，不扩大主区网格列或页头。

## 验证

- 375px 视口中，主区、页头、正文宽度均为 315px；修正前资源页主区曾被表格撑到 712px。
- 375px 与 1280px 各检查 18 个页面路径，共 36 次：三者宽度一致，页头圆角为 0、无可见阴影、左右内边距相同。
- 资源页窄屏截图确认标题、总数和导入按钮在页头内可见，资源表横向滚动。
